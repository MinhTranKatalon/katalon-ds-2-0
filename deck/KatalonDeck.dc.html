19 · Chart colour systemEight roles, four rules

Chart colour system

Data visualisation

Every chart in this deck draws from these eight roles. Pick by meaning, not by looks.

Series 1 · actual
--k-action-600 · #0f8461

The measured, current series. Also pass and on-target. One green per chart.

Series 2 · comparison
--k-slate-600 · #43509b

Prior period, plan, or the second category. The default series colour.

Series 3
--k-info-500 · #7a7aef

A third category only. Stop at three series plus a target line.

At risk · flaky
--k-warning-600 · #fed730

Fills only — a yellow label must be warning-800 or darker.

Fail · misses target
--k-fail-600 · #d14343

Below target, failed runs, negative variance. Never decorative.

Target · benchmark
--k-slate-300 · #c2c7e4

Dashed 3px line or a reference band. Never a data series.

Grid · axis
--k-gray-200 · #e1e7e4

Grid lines, axis rules, the unfilled track behind a bar.

Remainder
--k-gray-300 · #cdd6d2

The untaken share of a donut or progress bar.

Three series, then stop

A fourth colour makes a chart a puzzle. Split it into two charts instead.

Green means actual

Forest green is the measured series and nothing else — never the plan, never a category.

Colour carries one meaning

A hue means the same thing on every chart in the deck. Never re-use fail red as a category.

Label, never colour alone

Every series carries a text label in the legend or on the axis.

Three faces, one scale

Type system
Display · headings
Inter Tight
var(--k-font-display) · 600 · −0.03em
Slide titles, section dividers, big stat numbers, card headings. Weight 600 only — never 700, never Regular. Tighten tracking as size grows: −0.02em under 60px, −0.035em above 100px.
Body · UI
Inter
var(--k-font-body) · 400/500/600
Every sentence, bullet, label, table cell and caption. 400 for prose, 500 for labels, 600 only to mark one word. Line-height 1.45–1.5. Sentence case everywhere.
Mono · data
Restricted use
JetBrains
var(--k-font-mono) · 400/500
Only four jobs: the uppercase eyebrow (.12–.14em), numbers a reader compares digit by digit, timestamps and versions, and code. Nothing else.
Never a heading, bullet or sentence — one mono block per slide, plus the footer.

How to use this kit

Every slide here is a layout, not content. Pick the one that matches your point, replace the labels, delete the rest.

Step 01
Copy the deck

File → Make a copy. Never edit the master file — it is the source everyone pulls from.

Step 02
Apply a layout

One layout per idea: divider, numbers, table, flow, quote. Do not build a new one.

Slide › Apply layout
Step 03
Fill the boxes

Click a dotted box and type — the prompt disappears. Delete every box you do not fill.

Click › type › delete rest
Type scale

Heading 62. Body 24–30, never below 24. Inter Tight for headings, Inter for body, one weight step at a time.

One primary

Forest green carries every emphasis. Lilac, pink and yellow are card tints only — never a button.

4px accent, top edge

Cards carry one 4px line on the top edge, radius 16, 1px border. No shadows, no gradients.

Mono is rationed

JetBrains Mono for the eyebrow, numbers, dates and code — one block per slide, plus the footer.

Do
One idea per slide. Numbers before adjectives. Sentence case everywhere. Delete a card before you shrink the type.
Don't
No new colours, no emoji, no Title Case, no drop shadows, no body text under 24px, no fifth card in a four-card grid.
