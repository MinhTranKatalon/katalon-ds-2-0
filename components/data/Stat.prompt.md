A single figure that carries a point — pass rate, runs executed, active authors.

```jsx
<Stat value="91%" label="Median pass rate" trend="up" trendLabel="+5 pts" hint="vs Q2" />
```

Rules:
- Always give the window (`hint`). A number with no window is not evidence.
- `trend` needs `trendLabel` — the arrow alone is colour-and-shape only.
- Tabular figures, display face. Never invent a stat to fill a layout.
